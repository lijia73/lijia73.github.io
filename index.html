About Research Publications Experience

I work on agentic software engineering — building and rigorously evaluating code agents that reason over entire repositories, diagnose failures, repair programs, and learn from weak execution feedback.

My research connects code large language models with classical program analysis and reinforcement learning, with a strong emphasis on realistic, repository-level, industrial-scale evaluation. During 2025–2026 I worked as an algorithm research intern at WeChat, where several of these systems were deployed in production.

Research Interests

  • Repository-level agentic code reasoning and evaluation
  • Automated program repair and vulnerability repair
  • Whitebox software testing and compilation-error repair
  • Reinforcement learning for code agents (GRPO, RLHF, agentic RL)
  • Static analysis, dynamic slicing, and dependency-based localization

Publications

First author on all listed works.

  1. Signal Reshaping for GRPO in Weak-Feedback Agentic Code Repair

    Under review, NeurIPS 2026 · CCF-A

    Reframes weak-feedback multi-turn code repair as a GRPO trainability problem, using layered rewards, step-level process weighting, and failure-cause-aware rollout governance.

    arXiv

  2. Holmes: Multimodal Agentic Diagnosis for Mixed-Language Mobile Crashes at Industrial Scale

    FSE 2026, Industry Track · CCF-A

    A retrieve–explore–reason multi-agent system for post-mortem mobile crash diagnosis over WeChat's mixed-language codebase, reaching 87.6% function-level localization accuracy.

    Program

  3. From Laboratory to Real-World Applications: Benchmarking Agentic Code Reasoning at the Repository Level

    ACL 2026 Main, Oral · CCF-A

    Introduces RepoReason, a repository-level benchmark built on abductive assertion verification and execution-driven mutation, diagnosing aggregation deficits in frontier code agents.

    arXiv

  4. VulKey: Automated Vulnerability Repair Guided by Domain-Specific Repair Patterns

    FSE 2026 · CCF-A

    Guides vulnerability repair with a hierarchical abstraction of CWE/NVD expert knowledge, improving PrimeVul and Vul4J accuracy across languages and models.

    arXiv

  5. MioHint: LLM-Assisted Request Mutation for Whitebox REST API Testing

    ICSE 2026 · CCF-A

    Combines statement-level def-use analysis with LLM-generated mutation hints to escape fitness plateaus in whitebox REST API testing.

    arXiv

  6. ComBench: A Repository-level Real-world Benchmark for Compilation Error Repair

    Under review, ISSTA · CCF-A

    Mines and faithfully reproduces real C/C++ compilation failures from GitHub CI histories, exposing the gap between compilable and semantically correct LLM patches.

    arXiv
